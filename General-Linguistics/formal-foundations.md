# Formal foundations

The mathematics under grammar. This hub serves two vocabularies: it is a subfield of both General Linguistics and Computer Languages, which name the same subject from two directions, and it is the junction between them.

**Stub hub.** This note exists so the taxonomy is visible in the graph before the subfield has content; the breadth program in `ROADMAP.md` fills it in. Notes in this subfield set `belongs_to` here once it has an owner below the area hub.

## Topics owed to this hub

Generative grammar, formal semantics, dependency versus constituency, regular languages and automata, context-free grammars, BNF and EBNF, the lambda calculus, type theory, operational and denotational semantics, decidability and the halting problem.

# Mnamon

A curated scholarly guide to the ancient writing systems of the Mediterranean, maintained by the Scuola Normale Superiore in Pisa. Each script gets a signed overview, a bibliography and an annotated list of electronic resources, in Italian, English and French.

It is the closest thing the vault has found to a reference work covering exactly its Decipherment area, and unusually for a web resource it carries both a DOI and an ISBN, so it can be cited properly.

Pages used so far, each separately signed and cited to its editor rather than to the site:

- **Cypro-Minoan**, edited by Anna Cannavò (`page=Scrittura&id=34`), with its own DOI 10.25429/sns.it/lettere/mnamon003.
- **Phaistos Disc**, edited by Maurizio Del Freo (`page=Scrittura&id=22`).

`year` is the start of the copyright range stated in the site footer (2008-2025) and is a proxy for a resource that has no single publication date. Individual pages carry no visible revision date, so a fact taken from one should be cited with the access date.

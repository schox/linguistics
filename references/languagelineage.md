# Language Lineage

An interactive graph of 152 programming languages and 443 relationships, tracking what each language's compiler was written in and how implementations were bootstrapped.

Worth noting for the relationship type it records, which is unusual and more specific than "influenced by": *implemented in*. Bootstrapping gives programming languages a genealogy that natural languages do not have, since a language can be written in its own earlier self. That deserves its own field rather than being flattened into influence.

Authorship and data licensing are not stated on the site, so treat as link-only and attribute to the URL.

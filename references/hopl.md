# HOPL (Online Historical Encyclopaedia of Programming Languages)

A roster and genealogy of 8,945 programming languages from the eighteenth century onward, with roughly 7,800 influence links and over 11,000 citations. Created by Diarmuid J Pigott, maintained by Bruce M Axtens for entries from 1990 onward.

The influence links are the valuable part: this is the nearest thing to a Glottolog for programming languages, in that it holds relationships and not merely a list. It maps onto the `influenced_by` field on `ComputerLanguage` notes here.

**Not to be confused** with the ACM *History of Programming Languages* conference series, also abbreviated HOPL, which is a separate thing entirely (a set of proceedings, not a database). Cite carefully.

Licensing is not clearly stated, so treat as link-only rather than reusable data.

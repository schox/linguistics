# TIOBE index, August 2026

A monthly ranking of programming languages by popularity, used here as the selection instrument for which languages get a note, and for nothing else.

## What it establishes

The top twenty-five for August 2026, with ratings: Python 18.53%, C 11.10%, C++ 8.62%, Java 8.25%, C# 4.09%, JavaScript 2.63%, Visual Basic 2.18%, SQL 1.88%, R 1.56%, Rust 1.45%, Delphi/Object Pascal 1.37%, Scratch 1.27%, PHP 1.11%, Go 1.07%, Fortran 0.99%, Ruby 0.98%, Swift 0.96%, Perl 0.94%, COBOL 0.87%, Assembly language 0.86%, Ada 0.81%, Classic Visual Basic 0.81%, Objective-C 0.78%, SAS 0.76%, MATLAB 0.71%.

**What it measures**, in its own words: "an indicator of the popularity of programming languages", computed from "the number of skilled engineers world-wide, courses and third party vendors", using Google, Amazon, Wikipedia, Bing "and more than 20 others".

**What it does not measure**, also stated on the page: it is "not about the *best* programming language or the language in which *most lines of code* have been written". The page describes its intended use as checking whether skills are current, or deciding what to adopt for a new project.

## Access

Free. **The index is monthly and this note records the August 2026 snapshot**, which is what a citation of it means. A later month will rank differently, and the note should not be silently updated: a new snapshot is a new dated record.

## What it is used for here, and its limits

It answers one question only: which programming languages are widely enough used that a general reference should cover them. That is a popularity measure, and popularity is not importance. Three limits follow, and the selection built on it compensates for each rather than pretending otherwise:

1. **It is a search-and-vendor proxy.** The rating reflects how much material about a language exists online, not how much code runs.
2. **It systematically under-ranks historically decisive languages.** ALGOL, Simula, Smalltalk and ML shaped almost everything above them and appear nowhere in the top twenty-five.
3. **Whole paradigms are absent.** No pure functional language, no logic language, no concatenative language appears in the top twenty-five. A selection taken from this list alone would leave the paradigm hubs with no members.

The [Genealogy and lineages](../Computer-Languages/genealogy-and-lineages.md) hub records exactly which languages were taken from this list and which were added to cover the gaps.

# Olivier 2007

The critical edition of the Cypro-Minoan texts, cited throughout the literature as **HoChyMin**. It supplied the numbering that later work uses, so an inscription referred to as ##001 is HoChyMin ##001, and it retains the CM1/CM2/CM3 classification devised by Masson.

Superseded in coverage by [Ferrara 2013](ferrara-2013.md), which adds 27 inscriptions it did not include, but not displaced as the reference numbering.

The same Jean-Pierre Olivier co-edited [GORILA](godart-olivier-1976.md), the Linear A corpus. One editor is responsible for the standard editions of two of the Aegean undeciphered scripts, which is a fact about the size of the field as much as about him.

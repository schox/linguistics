# GEN 2024

A blog post tracing programming language use by decade from the 1980s to 2024, held as a second selection instrument alongside [TIOBE index, August 2026](tiobe-2026-08.md), and used for the set of languages it names rather than for any of its numbers.

## What it establishes

**The set of languages a forty-year view brings into frame.** It tracks sixteen: C, C++, Java, Python, JavaScript, PHP, Ruby, Go, Rust, C#, BASIC, Fortran, Pascal, Delphi, Lisp and Forth, plus an "Others" category.

That list is the reason it is held. A current popularity snapshot cannot see a language that mattered and stopped mattering, and this one independently names five that the TIOBE top twenty-five does not reach: BASIC, Pascal, Delphi, Lisp and Forth. Forth is the only concatenative language either instrument names, so without this source that paradigm would have no member at all.

Published 2024-06-25, updated 2024-09-03, by an author identified only as Richard, a senior partner at the firm.

## What it does not establish, and why the numbers are not used

**Its figures are explicitly the author's estimates.** The article describes its percentages as "best guesses" normalized across several indices including TIOBE, Stack Overflow surveys and GitHub data. It gives no methodology beyond that, no underlying data, and no account of how the sources were weighted.

So the percentages are not quoted here and no claim in this corpus rests on them. A self-published estimate normalized from other people's indices is two steps from a measurement, and the note that would use it should say what it actually wants: which languages a general reference should cover, which the set answers without the arithmetic.

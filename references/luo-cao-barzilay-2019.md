# Luo, Cao and Barzilay 2019

Frames decipherment as a minimum-cost flow problem, learning a character-level mapping between a lost script and a known language without parallel data. Evaluated on Ugaritic to Hebrew and Linear B to Greek, both cases where the answer is already known, which is what makes evaluation possible at all.

The important limitation is structural: the method needs a correct guess about which known language to align against. It does not find the relative, it exploits one.

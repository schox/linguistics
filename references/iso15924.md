# ISO 15924

The standard registry of script codes, each script carrying a four-letter code and a numeric code. Maintained by the Unicode Consortium as ISO's appointed Registration Authority.

The numeric ranges are themselves a typology: 000-099 hieroglyphic and cuneiform, 100-199 right-to-left alphabetic, 200-299 left-to-right alphabetic, 300-399 alphasyllabic, 400-499 syllabic, 500-599 ideographic, **600-699 undeciphered**, 700-799 shorthands and notations.

That undeciphered range is worth dwelling on: the international standard for naming scripts formally recognizes a category of scripts nobody can read, and assigns them codes anyway. It is external confirmation that script identity and script legibility are separate questions, which is the argument in [Script versus language](../Decipherment/script-versus-language.md).

Codes used in this vault: `Lina` (400) Linear A, `Linb` (401) Linear B, `Cpmn` (402) Cypro-Minoan, `Egyp` (050) Egyptian hieroglyphs, `Xsux` (020) Sumero-Akkadian cuneiform, `Inds` (610) Indus, `Latn` (215) Latin.

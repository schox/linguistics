# Etruscan alphabet

An Old Italic alphabet derived from the Euboean Greek script brought to southern Italy by colonists, used to write [Etruscan](../Human-Languages/etruscan.md) from about 700 BCE.

## The point of this note

The script is `deciphered` while the language it writes is only partly understood, and the vault can state that cleanly only because scripts and languages are separate notes joined by `writes` and `written_in`. Collapse them and the fact becomes unsayable.

Encoded in Unicode within the Old Italic block rather than separately, which is a reminder that ISO 15924 and Unicode carve the space by script family and not by language, for the same reason.

# Language

A specific human language, e.g. French, Akkadian, Noongar. `family` and `branch` place it genealogically, which is the canonical spine of the Human Languages area.

Era: living | historical | extinct | reconstructed.
Status: interested | learning | reference | reading | fluent.
Use `written_in` to link the `Script` notes that record it.

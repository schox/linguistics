# Note

A general working note or observation that does not yet belong under a more specific type. If it acquires a clear subject, retype it.

`status`: `open` (live, being worked on) | `draft` (incomplete, sources still missing) | `settled` (finished, sourced, unlikely to change).

## Body

A `Note` has no fixed skeleton, because it has no settled subject yet. It still opens by saying what it is about, and it still ends with `## Sources`. When it acquires a shape, retype it and adopt that type's skeleton.

This is also the type for **original analysis**: the cross-area synthesis, interpretation and theory that an entry is not allowed to carry. Such a note argues, and should. It links to the entries rather than living inside them.

Four conditions, set out in full under `## Drafting` in `CONVENTIONS.md`:

1. Typed `Note`, not an entry.
2. Says in its opening that it is analysis rather than a reported finding.
3. Every fact it rests on is sourced individually. The reasoning may be the author's; the premises may not.
4. States what would confirm or refute it, and whether anyone has tested it.

A prior published proponent is not required. Where the literature has someone arguing the same thing, cite them; where a search found nobody, record that the search was made.

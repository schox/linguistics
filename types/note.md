# Note

A general working note or observation that does not yet belong under a more specific type. If it acquires a clear subject, retype it.

`status`: `open` (live, being worked on) | `draft` (incomplete, sources still missing) | `settled` (finished, sourced, unlikely to change).

## Body

A `Note` has no fixed skeleton, because it has no settled subject yet. It still opens by saying what it is about, and it still ends with `## Sources`. When it acquires a shape, retype it and adopt that type's skeleton.

This is also the type for the vault's own analysis: the cross-area synthesis and interpretation that an entry is not allowed to carry. Such a note argues, and should, but it links to the entries rather than living inside them. See the parked list in `ROADMAP.md`.

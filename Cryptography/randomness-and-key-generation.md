# Randomness and key generation

Where keys come from. Random and pseudorandom bit generation, the statistical tests that judge them, and the failures that follow when generation is weak.

**Stub hub.** This note exists so the taxonomy is visible in the graph before the subfield has content; the breadth program in `ROADMAP.md` fills it in. Notes in this subfield set `belongs_to` here once it has an owner below the area hub.

## Topics owed to this hub

Random bit generation, pseudorandom bit generators, cryptographically secure pseudorandom generators, statistical tests for randomness, entropy sources and seeding, prime number generation, generators of high order, failures of randomness in deployed systems.

From [Menezes et al. 1996](../references/menezes-et-al-1996.md) chapters 4 and 5, and NIST's Random Bit Generation project. The handbook treats generation as a primitive with its own chapter rather than as an implementation detail, which is the reason this is a subfield here.

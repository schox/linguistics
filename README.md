# Linguistics

Tolaria vault for linguistics, human languages, computer languages, and cryptography: a reference archive of material and notes across all four.

## Start here

1. Read `CONVENTIONS.md`. How this vault is organised, the types, and the intake rules for new material all live there.
2. If you are an AI assistant, read `AGENTS.md` first. It is the canonical onramp.
3. Open the vault in Tolaria to browse by type and follow relationships.

## Layout

```
General-Linguistics/   Linguistics theory and related matters: phonetics, phonology, morphology, syntax,
                        semantics, pragmatics, historical and comparative linguistics, sociolinguistics, etymology
Human-Languages/        Specific human languages: grammar, vocabulary, courses, dictionaries, learning notes
Computer-Languages/     Programming, markup, query and formal languages: specs, references, notes
Cryptography/           Ciphers, cryptographic algorithms, cryptanalysis, crypto history
types/                  Tolaria type definitions
views/                  Saved sidebar views
attachments/            Images referenced from notes
```

Folders are for human navigation. Tolaria organises by the `type` field in frontmatter (see `CONVENTIONS.md`).

## Status

New vault. The four areas exist as empty MOCs, ready for material. Structure and types will be refined as content goes in.

## Git

This vault is a git repository. Remote: `https://github.com/schox/linguistics.git`. Tolaria has an in-app git client; standard git commands work from the terminal too.

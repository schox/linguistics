# Classic Maya

The language of the Classic-period inscriptions, described by Wikidata as the oldest attested member of the Mayan family. Written in [Mayan hieroglyphs](../Decipherment/maya-script.md).

## The living-relatives case

This is the configuration the vault has not had before, and it is the most favourable one possible.

[Egyptian](egyptian.md) survived as Coptic, in liturgical use, which gave Champollion a late readable form. [Akkadian](akkadian.md) had no descendant but had well-studied Semitic relatives. **Classic Maya has living descendants with millions of speakers**: the Mayan family includes Yucatec, K'iche', Ch'ol, Tzeltal, Tzotzil, Q'eqchi' and around thirty others, spoken today across Guatemala, Mexico and Belize.

So the language behind the script was never lost. What was lost was the ability to connect the script to it, which is precisely the [script versus language](../Decipherment/script-versus-language.md) distinction doing its work. A living language and an unread script coexisted for four centuries.

It also means the decipherment had a resource none of the others did: native speakers of related languages whose [phonology](../General-Linguistics/phonology.md) and [morphology](../General-Linguistics/morphology.md) could test a proposed reading directly.

## Open questions

- **This is a stub**, written so the script has a language to point at, as with [Egyptian](egyptian.md), [Akkadian](akkadian.md) and [Sumerian](sumerian.md). It has no treatment of the grammar, the corpus, or the relationship between the inscriptional language and the modern ones.
- **`branch: Ch'olan` is not sourced here.** The standard view identifies the language of the inscriptions with a Ch'olan variety, sometimes called Classic Ch'olti'an, but no source read for this batch states it, and the vault should not carry an unsourced genealogical claim. The glottocode `epig1241` reads as "Epigraphic Mayan", which is a different way of naming the same problem.
- **The claim about living descendants is general knowledge here, not cited.** It is not controversial, but it carries the argument of this note and should rest on Glottolog or a reference grammar.
- **`family: Mayan` matches the bolded family in `Human-Languages/_index.md`** under Languages of the Americas, which is the vault's own rule for that field.
- **`wals_code` not looked up.**
